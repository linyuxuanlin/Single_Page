# 驾驶实验室 · 倒车入库 MVP

Three.js 低速驾驶几何实验室。当前重点不是拟真动力学，而是确保科目二低速场景下的车辆几何关系可解释、可复现，并逐步增加真正有教学价值的分析能力。

## v0.2 物理模型

- 状态参考点固定为**后轴中心**，渲染与运动学共用同一坐标定义。
- 车头固定为局部 `-Z`；正速度=前进，负速度=后退。
- **W = 前进，S = 后退，A = 左转，D = 右转**；松开 A/D 后保持当前方向；Space 主动回正。
- 使用无侧滑 kinematic bicycle model 与精确圆弧积分。
- 前轮视觉使用 Ackermann 几何，不再让左右前轮保持完全相同的角度。
- 轮距、轴距、前后悬、车宽、轮胎宽度使用统一车辆参数。
- 实际轮迹、预测轨迹、参考轨迹都由同一套车辆几何/运动模型生成。
- 压线使用车身凸多边形与标线矩形的 SAT 相交检测，不再只检查四个角到标线的距离。
- 静止时预测方向使用当前挡位，行驶时使用真实速度方向。

## v0.3 教练分析层

新增 `coach.mjs`，把教学判断与底层车辆运动学分离：

- `predictLineRisk()`：沿当前挡位、方向盘角和同一套预测轨迹向前计算，返回是否会触线、首次触线姿态及距离。
- `predictedSweepSamples()`：返回未来各采样姿态的完整车身多边形，为车身扫掠区域可视化提供真实几何数据。
- `innerRearWheelKey()`：识别当前转弯的内侧后轮，供“内轮差”教学、后视镜强调和风险提示使用。
- `nearestReferencePose()`：找到标准入库轨迹上与当前后轴中心最接近的姿态，并给出训练进度。
- `referenceDeviation()`：在参考车辆局部坐标系中计算横向偏移、纵向偏移和航向角误差；横向正值表示相对参考轨迹偏右。
- `coachHint()`：按“即将触线 > 横向偏差 > 航向偏差 > 内轮差观察 > 路径清晰”的优先级输出结构化教学提示。

这一层不会改写车辆状态，也不复制另一套“教学专用轨迹算法”，因此教学提示与屏幕上的车辆运动保持一致。

## v0.4 双后视镜与移动端性能

- 新增左右实时后视镜，不创建额外 WebGL context，而是在主 renderer 上使用 scissor viewport 渲染两台镜面摄像机。
- 后视镜摄像机使用车辆局部坐标定位，会随车身姿态真实转动，并重点覆盖车侧、后轮与库线区域。
- 教练判断出当前内侧后轮后，会自动高亮对应后视镜并显示“观察这里”，让文字提示与视觉观察形成闭环。
- 增加“后视镜 ON/OFF”按钮和 `M` 快捷键。
- 车辆物理继续采用 120 Hz 固定步长；预测、扫掠和教练分析降为 20 Hz，避免重复计算占用主动画帧。
- 移动端后视镜约 30 fps 刷新，主画面仍按浏览器动画帧率渲染，以控制手机 GPU 压力。

## v0.5 训练复盘与个人最好成绩

`session.mjs` 已正式接入网页主循环，一次练习现在会形成完整的“训练 → 结算 → 复盘”闭环：

- 首次产生有效驾驶输入后自动开始训练计时，不需要额外点击“开始”。
- 网页约以 10 Hz 采样训练数据，避免把 120 Hz 物理循环中的每个状态都塞入会话，控制手机内存和评分计算开销。
- 每个样本记录后轴位置、速度、方向盘角、挡位、横向偏差、航向偏差、触线状态、是否入库成功以及当时的教练提示代码。
- 触线按“事件”计数：连续压线只记 1 次，离开后再次触线才新增一次，避免按帧重复扣分。
- 统计方向左右反复修正次数与前后挡切换次数，用于识别“碎方向”和不必要往返。
- 成功入库且低速稳定后自动弹出复盘卡；练习中也可以点击“复盘”或按 `P` 查看当前结果。
- 点击“重置”时，如果已经存在有效练习，会先显示本次复盘，避免误触后直接丢失练习结果。
- 复盘卡展示总分、等级、练习时长、行驶距离、最大横向偏差、最大航向偏差、最高速度、触线次数、方向反复修正次数、换挡次数和针对性建议。
- 扣分来源透明展示：触线、横向偏差、航向偏差、速度、碎方向和未完成均单独列出。
- 使用 `localStorage` 保存个人最佳分数，刷新页面后仍可看到历史最好成绩。
- `Esc` 关闭复盘，复盘卡内可直接“重新练习”。

## v0.6 长期训练趋势

`history.mjs` 已正式接入复盘页面：

- 每次**有效练习**首次结算时写入本地历史，最多保留最近 30 次。
- 同一练习反复打开复盘不会重复计入历史；空练习也不会污染趋势数据。
- 复盘卡新增最近窗口均分、相对上一窗口的升降趋势、最近完成率和历史最佳分。
- 基于近期表现自动给出一个最优先的长期训练重点，例如先稳定完成入库、减少触线、改善切入点或更早回正。
- 历史数据使用 `localStorage` 持久化；损坏或无效数据会通过 `parseHistory()` 安全恢复为空历史。

## 验证

```bash
node physics-tests.mjs
node coach-tests.mjs
node session-tests.mjs
node replay-tests.mjs
node history-tests.mjs
```

`physics-tests.mjs` 覆盖：坐标方向、直行、理论圆弧半径、前后可逆、W/S/A/D 语义、方向保持与回正、Ackermann、轮距一致性、SAT 压线、入库姿态、预测方向，以及参考轨迹全程不触线并最终完整入库。

`coach-tests.mjs` 覆盖：左右转内侧后轮判断、扫掠样本完整性、远离库线时无误报、在库内继续倒车时提前预测后库线风险，以及参考轨迹最近点、横向偏差方向和航向角偏差的教学判断。

`session-tests.mjs` 覆盖：成功练习高分、连续触线只计一次、离线后再次触线重新计数、方向左右反复修正计数、前后挡切换计数、严重偏差/高速/未完成练习的扣分，以及空会话的安全处理。

`replay-tests.mjs` 覆盖：关键训练事件、回放轨迹关键点保留、时间轴进度、插值、播放器状态与异常采样时间处理。

`history-tests.mjs` 覆盖：30 次滚动历史上限、最近窗口与上一窗口比较、完成率、最佳成绩、针对性训练建议，以及损坏本地数据的安全恢复。

网页模块可单独做语法检查：

```bash
# 将 index.html 内 type=module 脚本提取为 .mjs 后运行
node --check app.mjs
```

## 说明

这是驾驶几何教学工具，不用于替代真实驾校训练或官方考试判定。车辆参数目前为典型紧凑型轿车近似值，后续可做成车型配置。
